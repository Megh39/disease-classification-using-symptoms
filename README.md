# Disease Prediction using Symptoms (ML Project)

This repository contains an end-to-end machine learning pipeline for **disease classification based on symptoms**, using Logistic Regression and Naive Bayes models.

---

## 📊 Dataset

Dataset used: [Disease and Symptoms Dataset (Mendeley Data)](https://data.mendeley.com/datasets/2cxccsxydc/1)

The dataset contains over 240,000 samples with 300+ binary symptom features across 700+ disease categories.

**Note:** The dataset is **not stored in this repository** due to its large size.
